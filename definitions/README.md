# Definitions library

XDF (TunerPro) and other definition files, organized **by OS ID** — because
definitions pair with operating systems, not vehicles:

```
definitions/<OS-ID>/some-definition.xdf
```

Upload via the app (Tunes tab → Definitions) or drop files in manually.

## Rules

- Name the folder with the exact decimal OS ID (e.g. `12212156`).
- Keep a note of where each definition came from (forum thread, author,
  version) — add a `SOURCES.md` inside the OS folder when it's not obvious.
- Definitions are community work-in-progress: table addresses can be wrong.
  A value read through an XDF is a draft reading until verified.

## Where definitions come from

- pcmhacking.net XDF threads
- ls1tech.com "Bin and XDF Repository"
- gearhead-efi.com
- UniversalPatcher's XDF generator (when nobody has published one)
