Windows Setup — Tuning Garage

One-time setup to run the tuning repo and app on a Windows machine. About 15 minutes, most of it waiting on installers. Every link here opens in a new tab, so this page stays where it is.

1Install three tools

Install all three before doing anything else. Installer defaults are fine except where called out — those choices matter.

GitHub CLI

Download GitHub CLI ↗

Take the Windows .msi; defaults are fine.

Check all three installed

Open Command Prompt (press Start, type cmd, Enter) and run these one at a time — each should print a version number:

git --version
node --version
gh --version
"not recognized"? The PATH option was missed during that tool's installer. Reinstall it and check the PATH row in the tables above.

2Sign in to GitHub

gh auth login
  • What account? → GitHub.com
  • Preferred protocol? → HTTPS
  • Authenticate Git with your GitHub credentials? → Yes — this is what makes pushing work
  • How to authenticate? → Login with a web browser, then paste the one-time code into the browser window that opens

3Set your commit identity

Credentials and identity are different things. Signing in lets you push; identity is the name stamped on each commit. Without it, commits fail.

Run each line separately — PowerShell does not accept &&:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Use the same email as your GitHub account so commits are attributed to you.

4Clone the repo

cd %USERPROFILE%\Documents
gh repo clone YOUR-USERNAME/YOUR-REPO Tuning

That creates Documents\Tuning.

5Run it

Double-click start-tuning.cmd in the Tuning folder. It pulls the latest, starts the app, waits for the server to actually respond, then opens http://localhost:4590.

  • Handy: right-click start-tuning.cmd → Send to → Desktop (create shortcut)
  • Leave the black console window open while you work — closing it stops the server

Daily two-machine rhythm

Finish on a machine → Commit & push. Start on a machine → the launcher pulls (or hit Sync in the app).

  • If a machine is behind, the app shows ⇣ N behind GitHub in orange and warns you — Sync before doing anything.
  • Tuning tools save files wherever they like; use the app's upload forms so files land with correct names.
