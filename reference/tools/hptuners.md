# HP Tuners (VCM Suite + MPVI3)

**Role in my workflow:** primary commercial tuning suite — VCM Editor for table
edits, VCM Scanner for datalogging. MPVI3 is the interface.

## Notes as I learn

- Licensing: GM vehicles of this era are licensed per-VIN/OS with credits.
  Record what's been licensed in each vehicle's `vehicle.md`.
- File types: `.hpt` (tune), `.hpl` (datalog). Both binary — stored in git
  as whole files, no diffs.
- Scanner: build a channel list + histogram layout per goal (fuel trims vs
  knock vs idle) and save the layouts.
