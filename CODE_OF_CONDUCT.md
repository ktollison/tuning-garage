# Code of conduct

## The short version

Be decent. This is a hobbyist project about not blowing up engines.

## Specifics

- **Assume inexperience, not stupidity.** Everyone here is learning something
  that can destroy expensive hardware. "You should already know that" helps
  nobody.
- **Argue with the data.** Disagreement about a checksum, a scale, or a trim
  correction is the point of the project. Bring the log.
- **Do not post other people's data** — VINs, calibrations, or logs from a
  vehicle that is not yours.
- **Do not push someone toward a write they are not ready for.** If a person
  is unsure, the right answer is to slow down.

Harassment, personal attacks, and demeaning comments are not welcome, and
neither is derailing a technical thread with them.

## Enforcement

Report a problem to the maintainer through
[private vulnerability reporting](../../security/advisories/new) or by opening
an issue if it is not sensitive. Responses range from a request to edit a
comment through to a block, depending on severity. The maintainer decides, and
will say why.
